# Scope sandbox testing notice

This hosted environment is a hackathon prototype for testing with invented
commissions and PayPal Sandbox accounts. It is not a live payment service.
The example work does not create a real fulfilment commitment, and sandbox
payment amounts use test funds.

Keep real customer content, passwords, card details and other sensitive
information out of the prototype. Authenticate only on the provider's own
sign-in page. Scope never needs a PayPal password typed into an offer form.

An AI review supplies unverified suggestions. The creator must check the full
conversation, correct omissions, set the price and publish an exact revision.
The buyer separately reviews and accepts that revision. Joining an invitation,
copying suggestions, publishing or accepting does not request a payment.

Checkout may remain disabled while provider qualification is incomplete. An
uncertain action is checked against its original saved attempt; it is not
automatically retried. The free host can take 50 seconds or more to wake.
Availability, automatic data deletion and independent user benefit remain
unqualified. See [data use](SANDBOX_DATA_USE.md) before testing.

[MIT license](https://github.com/josepha-mayo/scope-before-payment/blob/main/LICENSE).
The current build status and limitations are described on
[Devpost](https://devpost.com/software/scope-before-payment).
